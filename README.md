# Eating Healthy - eBook & Video Course Store

A premium ecommerce landing page for selling the "Eating Healthy" eBook and video course bundle.

## Features

- 📚 Beautiful product showcase with image slider
- 💳 Integrated with Dodo Payments
- 🎁 Smart upsell system with discount popup
- 📱 Fully responsive (mobile & desktop optimized)
- ⭐ Customer reviews section
- ❓ FAQ accordion
- 📥 Automated download delivery

## Products

1. **eBook Only** - $19.99
2. **eBook + Video Bundle** - $39.98
3. **eBook + Discounted Video Bundle** - $29.98 (75% off video course)

## Tech Stack

- HTML5
- CSS3 (with custom animations)
- Vanilla JavaScript
- Dodo Payments integration

## Deployment

This site is deployed on Vercel at [www.eatinghealthly.shop](https://www.eatinghealthly.shop)

### Deploy to Vercel

1. Push this repository to GitHub
2. Import the project in Vercel
3. Deploy automatically
